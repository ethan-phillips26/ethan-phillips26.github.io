Whiteboard

web · 2026

A read-only front end for Blackboard Learn. Due dates, grades, announcements and assignment sheets each live on a different page for every course, so Whiteboard puts them on one screen: every deadline across every course, a calendar, grades that account for category weights, and a search box that covers assignments, announcements and the text inside handouts.

It runs entirely in the browser. A small Manifest V3 extension is the only part that ever touches Blackboard, and it only sends GET requests to the one server you connect. There's also a Claude tab that uses the Claude Code already on your computer.

DMR Hearings

search · 2026

Search across five years of North Dakota oil and gas hearings, where every result links to the exact second in the recording. The Industrial Commission streams every hearing to YouTube, which adds up to hundreds of hours of testimony, and the only way to find anything in it was to scrub through the videos.

I pull the auto-captions for every hearing since December 2021 (156 so far), split them into cases, and use the official dockets to fix the names the captions get wrong. Search runs keyword and embedding queries over overlapping 75-second chunks and merges them with reciprocal rank fusion, all in one SQLite file.

I use it through an MCP server with five tools, so Claude can search, read around the best hits and cite the case number, date and timestamp.
